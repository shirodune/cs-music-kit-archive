## Routing

- I18N-3 Every route has the locale as its first segment (`/{segment}/…`), including English. Built with Astro's i18n routing and `[locale]` dynamic routes in static output.
- I18N-4 `/` is a static page that picks a locale in this order: the remembered choice (`localStorage` key `mka:locale`), then the first of `navigator.languages` that matches, then `en`. Matching rules:
  - `zh-CN`, `zh-SG`, `zh-Hans*` → `zh-hans`; `zh-TW`, `zh-HK`, `zh-MO`, `zh-Hant*` → `zh-hant`; plain `zh` → `zh-hans`.
  - `pt-BR` → `pt-br`; any other `pt*` → `pt-pt`.
  - `es-ES` and plain `es` → `es`; any other `es-*` → `es-419`.
  - `no`, `nb`, `nn` → `nb`.
  - Otherwise match the primary subtag (`de-AT` → `de`).
- I18N-5 Choosing a locale in the language picker stores it under `mka:locale` and opens the same path in the new locale.
- I18N-6 Every page lists its 28 alternates with `hreflang` (using `tag`) plus `x-default` pointing at `en`.

## UI messages

UI strings are in `messages/{segment}.json`. English is the source.

```jsonc
{
  "nav.records": "Records",
  "artist.kitCount": { "one": "{count} kit", "other": "{count} kits" },
  "artist.yearsLater": { "one": "{count} year later", "other": "{count} years later" }
}
```

- I18N-7 Keys are flat, dot-separated strings. A value is either a string or a plural object.
- I18N-8 A plural object has one entry per CLDR plural category the locale uses, from `new Intl.PluralRules(tag).resolvedOptions().pluralCategories`. Today that is:
  - `other` only: vi, th, ja, ko, zh-hans, zh-hant
  - `one`, `other`: en, de, nl, da, nb, sv, fi, hu, tr, bg, el
  - `one`, `many`, `other`: fr, es, es-419, pt-br, pt-pt, it
  - `one`, `few`, `other`: ro
  - `one`, `few`, `many`, `other`: pl, cs, ru, uk
- I18N-9 Placeholders are `{name}`. The number in a plural message is always `{count}`.
- I18N-10 `t(key, values)` in `src/i18n/t.ts`:
  - Picks the plural form with `Intl.PluralRules(tag).select(count)`.
  - Formats numbers in placeholders with `Intl.NumberFormat(tag)`.
  - Falls back to the English string when the key is missing in a locale.
  - Is typed from `messages/en.json`, so an unknown key is a type error.
- I18N-11 `pnpm i18n:check` (run in CI) fails when, for any locale:
  - a key is not in `en.json`;
  - a plural object is missing a category the locale needs, or has one it does not use;
  - the placeholders differ from English.
  Missing keys are reported as warnings, because English fallback is allowed.
- I18N-12 Interactive React islands receive their strings as props from the page. No translation library ships to the browser.

## Formatting

- I18N-13 Dates are date-only values (`YYYY-MM-DD`). Format them with `Intl.DateTimeFormat(tag, { …, timeZone: "UTC" })` so the day never shifts.
- I18N-14 Durations are `m:ss`.
- I18N-15 Lists of names use `Intl.ListFormat(tag, { type: "conjunction" })`.
- I18N-16 Uppercase styling is done in CSS (`text-transform`) with the correct `lang`, never by changing the string.

## Text sources by kind

| Kind | Source | Translation |
|---|---|---|
| Kit names, kit descriptions, box names | Game localization files | Never edited or machine translated. Missing in a locale → English with `lang="en"` |
| UI messages | `messages/` | Machine translation allowed, reviewed by native speakers when possible |
| Stories and introductions | `content/` | Written in English first; Simplified Chinese next; others may be machine translated |

- I18N-17 Content with `translation: machine` shows a short notice saying so.
- I18N-18 When a story or introduction does not exist in a locale, the page shows the English text with `lang="en"` and a notice that it is not translated yet.

## Fonts

Each script group adds fallbacks after the Latin faces, so Latin text such as artist names keeps the design's type in every locale. Chosen on the specimen <https://claude.ai/artifact/CjfcNqJMpgT4XQCjsHXm99>.

| Group | Stencil heads | Condensed titles | Mono labels | Body |
|---|---|---|---|---|
| latin | Saira Stencil One | Saira Condensed | IBM Plex Mono | IBM Plex Sans |
| cyrillic | + Tektur | + Sofia Sans Condensed | IBM Plex Mono | IBM Plex Sans |
| greek | + Tektur | + Sofia Sans Condensed | + JetBrains Mono | IBM Plex Sans |

| ja | + Dela Gothic One | + Noto Sans JP | + IBM Plex Sans JP | + IBM Plex Sans JP |
| ko | + Black Han Sans | + Do Hyeon | + IBM Plex Sans KR | + IBM Plex Sans KR |

| zh-hant | + Noto Sans TC (900) | + Noto Sans TC (800) | + Noto Sans TC | + Noto Sans TC |

- I18N-19 Fonts are self-hosted and subset. A page loads only the Latin faces plus its own group.
- I18N-20 `font-synthesis: none` everywhere, so single-weight faces are never faux-bolded.
